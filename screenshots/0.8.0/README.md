# Highway Business Tycoon 0.8.0 · zrzuty z Godota

Galeria zawiera 35 nowych zrzutów z gry, w tym cztery profile dla każdej lokalizacji, panoramy i ustawienia. Dwanaście ujęć `0.7.0` pochodzi z osobnego uruchomienia commitu `aec0754`. Kamery scen porównawczych używają tych samych kątów. Wysoki zachowuje kontury budynków, kolorystykę i wyposażenie. Pojazdy i pracownicy poruszają się w czasie prób. Każde zdjęcie pochodzi z renderowanego okna Godota na Linuksie. [Metoda i pomiary](../../docs/performance-0.8.0.md)
