# Monetyzacja 2.0 · Galeria

Kadry pochodzą z Godot 4.7.2 na Linuksie. Próby dotyku wykorzystują zdarzenia ScreenTouch i ScreenDrag. Udostępnienie reklamy i potwierdzenie jej nagrody zasymulowano przy granicy SDK w skrypcie testowym. Scena, UI, zarządzanie kontekstem, zapis oraz nagrody są realizowane przez właściwy kod aplikacji.
