# IARC · kwestionariusz ratingu

W **App content → Content rating → Start questionnaire** podaj `kogonowski52@gmail.com`. W typie wybierz grę. Odpowiedz zgodnie z treścią tego zamkniętego wydania. Nazwy i szczegółowość pytań mogą się różnić między kontami.

| Pytanie o zawartość w grze | Odpowiedź i uzasadnienie |
| --- | --- |
| Przemoc, obrażenia, broń, krew | Nie. Pojazdy i postacie wykonują usługi. Mechanika ruchu i warsztat dotyczą napraw, parkowania i kolejkowania. |
| Strach, przerażające sceny | Nie. Pogoda, noc i trasy służą oprawie kompleksów. |
| Wulgaryzmy | Nie w sprawdzonych tekstach, interfejsie i treści gry. |
| Alkohol, tytoń lub narkotyki | Nie w zaprojektowanych mechanikach. Restauracja jest zwykłą usługą. Katalog nie oznacza alkoholu, tytoniu ani narkotyków jako produktów. |
| Treść seksualna i nagość | Nie. Mapa przedstawia personel i klientów stylizowanej stacji. |
| Hazard, zakłady lub symulowany hazard | Nie. Waluta służy rozbudowie, a nie zakładom, ryzykowaniu stawek lub wypłacie środków. |
| Płatne losowe nagrody | Nie. Nagrody z reklam mają podaną zawartość, a zaprojektowane pakiety mają stałe składniki. |
| Prawdziwe zakupy cyfrowe | Nie w `closed`. Płatności są wyłączone w manifeście i przy próbie otwarcia. Po zmianie konfiguracji zaktualizuj odpowiedź. |
| Interakcje między użytkownikami, UGC, czat lub udostępnienie lokalizacji innym graczom | Nie. Kampania jest jednoosobowa. Gra nie publikuje treści graczy i nie przekazuje im wzajemnie położenia. |
| Reklamy zewnętrzne | Tak, gdy formularz o to pyta. To odrębny temat od treści gry. Nie przewidujemy kreacji sieci Google ani ich ratingu. |

Zapisz formularz i odczytaj rzeczywiste wyniki IARC. Ostateczną klasyfikację wydają właściwe organy w systemie IARC. [Oficjalna klasyfikacja treści](https://support.google.com/googleplay/android-developer/answer/9859655)
